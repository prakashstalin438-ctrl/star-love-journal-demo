# STAR Love Journal — Public Concept Demo

This is an isolated, independently deployable public concept demo of the **STAR Love Journal** application designed by **Stalin AI Studio**.

## Privacy Assurance
- **100% Mock & Fictional Data:** All names, memories, dates, voice notes, and letters are sample mock content.
- **No Credentials:** Zero Firebase keys, zero authentication, zero cloud database connections, zero private data.
- **Royalty-Free Imagery:** All sample photography sourced from Unsplash.
- **Synthesized Audio:** Uses Web Audio API to simulate voice memos without real audio recordings.

## Quick Start
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
Outputs static files to `dist/`, ready for instant deployment to Vercel, Netlify, or Firebase Hosting.
